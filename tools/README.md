# Grow your own C

The profile artwork is generated by [`grow.py`](./grow.py). It uses only Python 3's
standard library—no packages, network requests, or image tools required.

From the repository root:

```sh
# Recreate the profile artwork (seed 23).
python3 tools/grow.py

# Grow a different version without overwriting the profile's assets.
python3 tools/grow.py --seed 42 --output-dir ./my-growth
```

Each run writes `growth-light.svg` and `growth-dark.svg`. Existing files with those
names in the output directory are overwritten. The default output directory is
this repository's `assets/`, regardless of where you run the script. A custom
relative output path is relative to your current directory.

## How it grows

An uneven, open arc forms the stem. Random attraction points surround it. Nearby
branches grow toward those points, forking as their directions diverge. The
resulting tree becomes smooth SVG curves, with thicker strokes near the root and
a small ochre dot marking the beginning.

Change `--seed` to explore different branching patterns. To go further, edit the
attraction-point ranges or growth distances in `grow()`, or the `THEMES` colors.
The same seed and settings reproduce the same artwork in the same Python
environment; tiny floating-point differences across platforms may affect output.
